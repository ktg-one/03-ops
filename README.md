# 03-ops

Good AI's operating vault skeleton. Open this folder in Obsidian as a vault and start at `00-START-HERE/index.md`.

Role personas (CMO, CFO, COO) for Claude Code live in `.claude/agents/`. Launch one with `claude --agent cmo`. See `00-START-HERE/personas.md`.

This repository is public. Keep client details, the business plan, financials and anything personal out of it; those belong in the private vault copy only.
